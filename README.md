# HR Строяков 2.1 — версия для Layero

Самостоятельное веб-приложение для HR-процессов. В меню сохранены 12 функциональных блоков, но в версии 2.1 активны только **HR Pulse**, **Реестр офферов** и **Табель**. Остальные блоки видны серыми и не открываются; их код и данные сохранены для последующего возвращения.

## Что изменилось

- веб-интерфейс собирается Vite и разворачивается на Layero;
- рабочая база — PostgreSQL через Layero Data API;
- вход пользователей — Layero Auth, совместимый с GoTrue;
- серверные SQL-функции проверяют роли и доступ к сотрудникам;
- локальный предпросмотр использует IndexedDB и работает без аккаунта Layero;
- данные предпросмотра можно выгружать и загружать в JSON;
- добавлен конвертер текущих Excel-книг Google-версии в формат базы 2.0;
- табель формируется, массово редактируется, сверяется с Excel СКУД и выгружается в цветной `.xlsx` прямо в браузере.
- реестр офферов хранит ФИО, подразделение, должность, текущую сумму, дату и статус;
- мотивация состоит из редактируемых условий и сохраняется только новой версией, поэтому прежние варианты доступны в истории;
- HR и HRD могут создавать и подтверждать исключения из табеля внутри модуля «Табель».

## Два режима одной кодовой базы

```text
npm run dev без .env.local
└─ IndexedDB браузера + демонстрационные данные

Layero / .env.local с VITE_LAYERO_DATA_*
└─ Layero Auth + Data API + PostgreSQL
```

Приложение само выбирает режим. Если обе переменные Layero пусты, включается безопасный локальный предпросмотр.

Репозиторий содержит только вымышленные демонстрационные записи. Рабочие HR-данные, исходные Excel-файлы и `.env.local` в Git не включаются.

## Быстрый предпросмотр

Требуется Node.js 22 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. В верхней панели появится кнопка **«База предпросмотра»**. Через нее можно:

- увидеть количество записей по наборам данных;
- проверить интерфейс под ролью HRD, HR, руководителя или табельщика;
- скачать резервную копию JSON;
- загрузить JSON, подготовленный конвертером;
- вернуть исходные демонстрационные данные.

## Проверка

```bash
npm test
npm run build
```

Готовая статическая сборка создается в `dist/`. Исходный проект следует передавать Layero целиком: платформа сама выполнит `npm install` и `npm run build`.

## Важное ограничение Layero

По состоянию на сентябрь 2026 года базы данных и Data API Layero доступны в закрытом пилоте. Если в панели нет раздела **«Базы данных»**, запросите включение через чат поддержки Layero. До включения рабочего PostgreSQL весь интерфейс можно полноценно проверять в локальном режиме.
