# Перенос данных из Google-версии

Конвертер читает экспортированные `.xlsx` основной HR-книги и отдельного табеля и создает резервную копию JSON версии 2.0.

## 1. Сделайте резервные копии

В Google Sheets скачайте обе рабочие книги через **Файл → Скачать → Microsoft Excel (.xlsx)**. Не используйте старые шаблоны, если в рабочих книгах уже есть актуальные записи.

## 2. Запустите конвертер

```bash
node scripts/convert-google-workbooks.mjs \
  --hr "HR_основная.xlsx" \
  --timesheet "HR_табель.xlsx" \
  --out "HR_Строяков_перенос_2.0.json"
```

В Windows PowerShell команда может быть записана одной строкой:

```powershell
node scripts/convert-google-workbooks.mjs --hr "C:\Путь\HR_основная.xlsx" --timesheet "C:\Путь\HR_табель.xlsx" --out "C:\Путь\HR_Строяков_перенос_2.0.json"
```

В конце появится отчет с количеством записей по каждому набору.

## 3. Сначала проверьте локально

1. Запустите `npm run dev` без `.env.local`.
2. Нажмите **«База предпросмотра»**.
3. Загрузите подготовленный JSON.
4. Проверьте сотрудников, справочники, адаптацию и несколько месяцев табеля.
5. Сформируйте контрольный Excel.

## 4. Загрузите в Layero

После SQL-миграции и назначения первого HRD войдите в рабочий интерфейс, откройте **«База данных»** и загрузите тот же JSON.

Загрузка выполняет upsert: запись с тем же ключом обновляется, отсутствующая создается. Перед повторной загрузкой скачайте текущую JSON-копию рабочей базы.

## Что переносится

- сотрудники и даты приема/выхода;
- кадровые события;
- вакансии и кандидаты;
- адаптация, шаблоны, обучение, документы и опросы;
- справочники, настройки, роли, календарь и контроль качества;
- периоды и дневные записи табеля;
- импорты СКУД, расхождения, контроль, коды и правила доступа.

Формулы переносятся как их последние рассчитанные значения. Оформление служебных листов и изображения не переносятся: визуальный формат веб-интерфейса и итогового Excel формируется программой.
